EpiChat is a prototype from the Emory Disruptive Discovery Seed Program (FY27). Its premise is simple — the engine for simulation-based epidemiology already exists. What's missing is an interface that non-modelers can actually use.

[01 / opportunity]
LLM + structured API

What's missing is an interface.

01

LLMs now reliably generate structured code from natural language in scoped domains.

02

Starsim's declarative, template-friendly parameter and model interface is an ideal target for LLM-driven code generation.

03

Most policy questions reduce to a handful of well-bounded model classes — SIR, SEIR, SIS, etc.

Yuke's research sits at the intersection of infectious disease epidemiology, environmental health, and computational modeling. Recent work has focused on diarrheal disease transmission, WASH interventions, and the infrastructure that lets modelers and non-modelers collaborate on policy-relevant questions.

EpiChat grew out of repeated conversations with health analysts and surveillance officers who could articulate exactly the question they needed answered — but had no way to get to a modeled answer in less than weeks.
